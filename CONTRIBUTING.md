# Contributing to MaxPS4

Thank you for your interest in MaxPS4.

MaxPS4 is a community project experimenting with PS4 emulation on iPhone, building on FEXCore, shadPS4 and AetherPS4.

## How to contribute

You can contribute by:

- reporting bugs through GitHub Issues;
- proposing fixes and improvements through Pull Requests;
- testing iOS builds and sharing reproducible logs and MaxPS4 reports;
- improving the interface, documentation and iOS compatibility;
- helping with emulation and game compatibility work.

## Before a Pull Request

1. Describe the problem or improvement clearly.
2. Keep changes focused and documented.
3. Check that the project builds as far as possible.
4. Do not include any PS4 game, commercial PKG, key, firmware, protected content or other material you do not have the right to redistribute.
5. Respect the licenses of the third-party projects MaxPS4 uses.
